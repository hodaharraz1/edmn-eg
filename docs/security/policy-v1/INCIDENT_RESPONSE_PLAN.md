## 1. الأدوار (تحتاج أسماء ووسائل اتصال، ولا تُكتب في Git)

| الدور | المسؤولية | المعيَّن |
|---|---|---|
| قائد الحادث | القرار والتنسيق والتصعيد | **غير معيَّن** |
| المسؤول الأمني | التقييم الفني والاحتواء والأدلة | **غير معيَّن** |
| مسؤول المال (`finance.controls`) | الإيقاف الطارئ والمطابقة. **شخصان** لرفع الإيقاف | **غير معيَّن** |
| المطور المناوب | الإصلاح والنشر بعد الموافقة | **غير معيَّن** |
| القانوني والتواصل | الإخطارات للجهات والعملاء | **غير معيَّن** |

## 2. التصعيد

الخطورة حسب `INCIDENT_RESPONSE.md`:
- **SEV-1:** أي خطر على المال أو الهوية، أو كشف بيانات. **دائمًا**: أي اختلال في الدفتر، أو صرف خاطئ، أو كشف رقم قومي أو بيانات بنكية، أو تسريب مفتاح إنتاج.
- **SEV-1:** إبلاغ قائد الحادث والمسؤول الأمني فورًا، والمالك خلال 30 دقيقة.

## 3. إجراءات الاحتواء (SEC-147)

| الحالة | الإجراء الفوري | الأداة الموجودة |
|---|---|---|
| خطر مالي | إيقاف طوارئ عام: يمنع حركة المال ويُبقي الدخول والدعم | `/admin/finance-control`، مدقَّق `killswitch.global_engaged`، يحتاج 2FA حديثًا |
| حساب مستخدم مخترق | إلغاء كل جلساته وأجهزته، وتعطيل الحساب | قائمة الجلسات + أدوات الإدارة (مدقَّقة) |
| حساب موظف مخترق | تعطيل الموظف، إلغاء الجلسات، مراجعة `audit_logs` بالـ `actor` | `rbac/staff.ts` |
| تسريب مفتاح | تدوير فوري. `SESSION_SECRET` يُبطل كل الجلسات، `DATA_ENCRYPTION_KEY` عبر `_PREVIOUS` + `reencrypt.ts`، `MOBILE_TOKEN_KEY` يُبطل رموز الموبايل | `SECRET_ROTATION.md` |
| تسريب في تطبيق موبايل | رفع `minSupportedVersion` لإجبار التحديث | `/api/v1/app/config` |
| هجوم على الخدمة | وضع الصيانة + حماية Vercel | `maintenanceMode` في الإعدادات |
| ملف خبيث | العزل (الملفات غير المفحوصة غير متاحة) | `STORAGE_OUTAGE.md` |

## 4. التحقيق

1. ابدأ الجدول الزمني بتوقيت UTC: من فعل ماذا، ومعرّفات الطلبات (`x-request-id` ← `audit_logs.request_id`).
2. لقطة صحة الدفتر (Ops ← «شغّل فحص الآن») قبل أي تصحيح.
3. لا تعدّل بيانات الإنتاج يدويًا. التصحيحات المالية عبر قيود تسوية بـ Maker/Checker فقط.

## 5. حفظ الأدلة (SEC-148)

- **ما يُحفظ:** صادرات `audit_logs` و`error_events` وسجلات المزوّد للفترة، مع بصمة SHA-256 لكل ملف.
- **أين:** تخزين منفصل بصلاحية قراءة فقط.
- **ممنوع:** نسخ أسرار أو أرقام قومية إلى تذاكر أو محادثات.

## 6. الإخطارات (SEC-149، يحددها القانوني)

- **مصر:** قانون حماية البيانات الشخصية 151/2020 يلزم بإخطار المركز المختص والأشخاص المتأثرين في حالات الخرق. المدد والصيغة **يحددها المستشار القانوني** قبل الإطلاق.
- **الأموال الحقيقية:** إخطار مزوّد الدفع والبنك الشريك وفق التعاقد.
- **المورّدون:** إبلاغ المورّد المعني إذا كان مصدر الحادث (Vercel، Neon، مزوّد SMS أو البريد).

## 7. ما بعد الحادث (SEC-150)

- **الختام:** رفع الإيقاف الطارئ **بشخصين** فقط.
- **تقرير خلال 5 أيام عمل:** السبب، الأثر (المستخدمون والمبالغ)، الأدلة، الإصلاح، اختبار الانحدار، تحديث سجل الثغرات والضوابط.
- **تمرين:** محاكاة ربع سنوية، أولها قبل الإطلاق. **لم يُجرَ بعد.**
