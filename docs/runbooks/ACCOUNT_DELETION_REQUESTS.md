# طلبات حذف الحساب

> مبني على `src/server/modules/customers/closure.ts` وصفحة `/admin/closures` ومسارات `/api/v1/me/deletion-request`. **الإغلاق = تجهيل بيانات التعريف مع الاحتفاظ بالسجل المالي. مفيش حذف فعلي لأي بيانات مالية.**

## دورة الطلب
1. العميل يرسل الطلب من التطبيق (`POST /api/v1/me/deletion-request`). مفيش شاشة ويب للطلب.
2. لو في أي التزام مفتوح الطلب يتسجل بحالة `BLOCKED` برسالة بالأسباب (مثل: طلبات جارية، دفع قيد المراجعة، مرتجعات أو استردادات أو نزاعات مفتوحة، صفقات محمية، رصيد لا يساوي صفر، سحب مفتوح، متجر نشط، تجميد مالي). العميل بيحل الأسباب ويعيد الطلب. **ده «الرفض بسبب».**
3. لو مفيش موانع الحالة `PENDING`. العميل يقدر **يسحب** الطلب (`/cancel`) قبل التنفيذ فتبقى `WITHDRAWN`.
4. الإدارة تنفذ من `/admin/closures` (صلاحية `customers.manage`).

## تنفيذ الإغلاق (للموظف)
1. افتح `/admin/closures` وراجع الطلبات `PENDING`.
2. **الإغلاق يحتاج موظفين اتنين مختلفين وكل واحد بـ step-up طازة (PKG-SEC-FIX-01).** الموظف الأول يضغط «طلب التنفيذ». الطلب بيفضل `PENDING` ويظهر «مستني موظف تاني». أي طلب `PENDING` موجود قبل التحديث لازم يبدأ بالخطوة دي.
3. موظف تاني (غير الأول) يضغط «تنفيذ الإغلاق (يُعاد فحص الموانع)». النظام بيعيد فحص كل الموانع تحت قفل الحساب. لو ظهر مانع جديد الطلب يرجع `BLOCKED` ولا يتنفذ. عند النجاح بيتمسح كمان رموز الإشعارات والأجهزة وصور الهوية (لغير حسابات البائعين) بحسب PKG-SEC-FIX-02.
3. لو سليم: الحساب يبقى `CLOSED`، والاسم يتحول لـ«حساب مغلق»، والبريد والموبايل والسر الثنائي يتمسحوا، والعناوين تتأرشف، والجلسات تتلغي، والعميل ياخد إشعار (داخل المنصة + بريد) قبل مسح بريده.
4. **بيتحفظ:** الطلبات والمدفوعات والدفتر والاستردادات والسحوبات والنزاعات والرسائل وسجل التدقيق والأدلة.

## قواعد
- لا تغلق حساب موظف (يرفض) ولا حسابك أنت.
- لا تمسح بيانات بالـSQL. لو العميل بيطلب مسح الصور أو الرسائل نفسها، ده قرار قانوني وليس تشغيلي: وثّق الطلب وارفعه للمالك.

## فجوة معروفة (للمراجعة القانونية)
صور البطاقة لحساب مغلق بتتقفل عند الإغلاق وبتفضل محفوظة، ومفيش مسح تلقائي لحد ما المالك يقرر (قرار المالك 2026-11-25). النص المنشور بيقول إن الصور بتتحذف، فمحتاج نسخة جديدة قبل المتاجر: النص المقترح في `docs/store/ACCOUNT_DELETION_PAGE.md`.

## التدقيق
`account.closure_requested` و`account.closure_blocked` و`account.closure_withdrawn` و`account.closed`.
