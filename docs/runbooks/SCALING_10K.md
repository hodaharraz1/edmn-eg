# التكبير من سيرفر واحد لحد 10,000 متزامن — PKG-INFRA-01

**كل الأرقام هنا تقديرات تصميم مني (Instinct)، مش قياس ومش عرض سعر.** مفيش اختبار ضغط HTTP اتشغّل في بيئة الحزمة،
فالأرقام دي **لم يتم التحقق** لحد ما تتشغّل على السيرفر وتتجمع الأرقام الحقيقية.

## السلّم

| المرحلة | المتزامن المتوقع | البنية | القياس المطلوب قبل الانتقال |
|---|---|---|---|
| 1 | لحد ~300 | سيرفر واحد: nginx + web (1–2 instance) + worker + Postgres + Redis | `k6` على المسارات الستة: p95 < 800ms، أخطاء < 1% |
| 2 | 300–1,000 | نفس السيرفر + PgBouncer + Redis + 2 web instances | CPU < 60% عند الذروة، `edmn_jobs_backlog` ثابت |
| 3 | 1,000–3,000 | سيرفر تطبيق منفصل عن سيرفر القاعدة + replica للقراءة + CDN للصور | زمن الاستعلام p95 على القاعدة < 50ms |
| 4 | 3,000–10,000 | 2–4 سيرفر تطبيق خلف موازن + Postgres أساسي وreplica + CDN + كاش صفحات | اختبار ضغط على بيئة معزولة بنفس الشكل |

## التكلفة التقديرية (شهريًا)

| البند | المرحلة 1 | المرحلة 4 |
|---|---|---|
| سيرفر تطبيق (4 vCPU / 8 GB) | 25–40 دولار | 2–4 × 25–40 = 50–160 دولار |
| قاعدة بيانات (4 vCPU / 16 GB) + replica | 0 (على نفس السيرفر) | 60–120 دولار (مُدارة) أو 40–80 (ذاتية) |
| Redis صغير | 0 (كونتينر) | 10–15 دولار |
| تخزين كائنات + خروج بيانات | 5–15 دولار | 20–50 دولار |
| مراقبة (Prometheus/Grafana) | 0 | 0–30 دولار |
| نسخ احتياطي خارجي (PITR) | 5–10 دولار | 15–30 دولار |
| **الإجمالي** | **~35–65 دولار** | **~155–405 دولار** |

بالجنيه (بسعر تقديري 48 ج.م للدولار): المرحلة 1 ≈ **1,700–3,100 ج.م**، المرحلة 4 ≈ **7,400–19,400 ج.م**.
ده أرخص من رقم 600–1,200 دولار اللي في PKG-AUDIT-01 لأنه كان بيفترض بنية مُدارة بالكامل من أول يوم.

## إزاي تطلع الأرقام الحقيقية (الأمر اللي بيثبت كل ده)

```bash
# على السيرفر نفسه، بمقاس الإنتاج:
docker compose -f deploy/compose/docker-compose.prod.yml -f deploy/compose/docker-compose.extra.yml up -d
BASE_URL=http://127.0.0.1:3000 k6 run perf/k6-api.js          # p50/p95/p99 + نسبة الأخطاء
# ومع القياس: grafana + ops/prometheus/edmn-alerts.yml
```

## ملاحظات تشغيلية

- **PgBouncer بـ`POOL_MODE=transaction`**: يمنع `LISTEN/NOTIFY` والـprepared statements عبر الجلسات. لو الكود بيستخدم أي منهما، استخدم `session` mode أو اربط الـworker مباشرة بالقاعدة.
- **Redis** بيحمل عدّادات الحدود بس (PKG-PERF-01)؛ ضياعه بيعيد ضبط النوافذ الجارية، ومش بيأثر على أي فلوس.
- **الصور** لازم تتقدم من CDN، مش من التطبيق؛ `/media` بيرجّع كاش سنة immutable للملفات CLEAN فده جاهز.
- **القاعدة**: أي قراءة تقيلة (تقارير، تصدير) تتشال على replica الأول قبل أي تكبير أفقي.
