- Real Money OFF؛
- لا نشر على Vercel، ولا TestFlight؛
- لا مفاتيح توقيع إنتاجية، ولا Firebase، ولا APNs.

## 2. الاتصال بخادم الاختبار المحلي (تم في بيئة البناء)

**الإعداد:**
- قاعدة بيانات محلية جديدة، جُهّزت بالأمر `npm run db:setup` كما في الدليل؛
- `npx next dev -H 0.0.0.0 -p 3000`؛
- `npm run worker`.

الخادم يجيب على كل واجهات الشبكة (loopback وعنوان الشبكة)، و`/api/v1/app/config` يعيد `realMoneyEnabled:false` و`currency:EGP`.

**الفحص:**
- شغّلت **كود العميل الفعلي للتطبيق** (`ApiClient` + `MobileApi` + dio) من Dart VM ضد الخادم، عبر عنوان الشبكة، لا localhost.
- كان ملف فحص مؤقتًا وحُذف بعد التشغيل.

## 4. حالة اختبار iPhone

**لم يُنفَّذ بعد.** لا يوجد Mac ولا iPhone متصل بهذه الجلسة؛ بيئة البناء Linux بلا Xcode.

ما تم التحقق منه من الكود دون جهاز:
- المشروع يستخدم Swift Package Manager، والإضافات الثلاث تدعمه.
- حد iOS الأدنى (15.0) أعلى من حد كل إضافة.
- `Info.plist` يحتوي `NSAllowsLocalNetworking` ونص إذن الشبكة المحلية.
- التوقيع `Automatic`، بلا Team مثبّت في المشروع، فكل مختبر يوقّع بحساب التطوير الخاص به.

لا توجد بعد أي نتيجة تشغيل أو لقطة من iPhone.
